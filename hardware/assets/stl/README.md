# Printable STL Files

3D-printable parts for the rig. Open in a slicer (PrusaSlicer, Cura) or a
3D viewer; all are in millimetres.

| File | Part |
|---|---|
| `cart_3d_print.stl` | Cart body that rides on the LEFB32NXS slide; holds the arc + ball |
| `arduino-mount.stl` | Bracket for the Arduino Uno sensor board; mounts on the rig frame, off the cart |
| `motor-rail.stl` | Motor mount / rail |
| `base-part-1.stl` | Base assembly (part 1 of 2) |
| `base-part-2.stl` | Base assembly (part 2 of 2) |

Recommended print settings (PLA): 0.2 mm layer height, 30 % infill,
supports for overhangs, 0.4 mm nozzle. See `BOM_AND_ASSEMBLY.md` for
mechanical context.
