## Reproducibility

All data backing every figure and table lives in `paper/data/` at the repo root. The data README (`paper/data/README.md`) maps each subdirectory to the corresponding paper section.

### Regenerate figures

```bash
cd paper/ram
python regenerate_all_figures.py     # ALL figures (canonical, one command)
# Individual generators (each owns a disjoint set of figures):
python regenerate_figures.py           # Main-paper figures
python regenerate_extra_figures.py   # Supplementary trajectories/action profiles/diagnostics
python scripts/verify_supplementary_claims.py   # Recompute every numeric claim
```

### Reproduce statistics and tables

`paper/scripts/compute_statistics.py` is the single source of truth for
Table I and the Section V statistics: success rate with Wilson score
intervals, settling median [IQR] over successful trials, RMS effort,
Bonferroni-corrected Mann-Whitney significance (successful-trial settling
times), and Fisher's exact tests for success-rate differences.
`paper/scripts/analyze_exp.py` reports the same statistics alongside
compute-time / ISE diagnostics for exploratory analysis.

```bash
cd paper/ram
export PYTHONPATH="$PWD/../..:$PWD/../.."   # repo root on sys.path
python ../../scripts/analyze_exp.py \
  --exp 1 \
  --files ../../data/exp1_hardware/consolidated.json \
  --outdir /tmp/exp1_stats
# Writes: exp1_paper_table.csv   -> Table I
#         exp1_significance.csv  -> broad per-variant exploratory matrix
#         exp1_cohens_d.csv, exp1_full_diagnostic.csv
#         exp1_compute_times.{pdf,png}, etc.
```

The committed `data/exp1_hardware/exp1_significance.csv` is the
13-benchmark-controller pairwise settling-time significance matrix
(Mann-Whitney, Bonferroni-corrected `alpha = 0.05/78`; 18 significant
pairs), regenerated by `paper/ram/regenerate_extra_figures.py` from the
same computation as `figures/exp1_significance_heatmap.png`, so the two
always agree. (The `analyze_exp.py` command above instead writes a
broader per-variant exploratory matrix to its `--outdir`.) The `--files`
flag defaults to `consolidated.json`; omit `--exp` for the full summary.

## Controller Taxonomy

The paper uses a two-axis taxonomy:

1. **Data/model source:** analytical model, simulation, hardware logs
2. **Decision mechanism:** feedback law, MPC/planning, online RL policy, offline RL policy

| Controller | Data source | Decision mechanism |
|-----------|-------------|-------------------|
| PD + WO, LQR + WO, SMC + WO | Analytical model | Feedback |
| MPC + WO, NMPC | Analytical model | MPC/planning |
| PPO (BZ+DR), TRPO, SAC, TD3, TQC | Simulation | Model-free RL |
| PPO (WM) | Hardware logs | Policy in learned world model |
| MPPI | Hardware logs | Sampling-based MPC |
| IQL | Hardware logs | Offline model-free RL |
